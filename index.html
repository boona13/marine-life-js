How it works: the top-down image is cut into N horizontal strips. Each strip is drawn at an offset along a traveling sine wave whose amplitude grows from head→tail — pure Canvas2D drawImage calls, no shaders, no spritesheets. The same trick ports 1:1 to a vertex shader on a tessellated quad if you ever want it on the GPU.
